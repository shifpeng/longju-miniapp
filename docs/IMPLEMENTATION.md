# 成员端实现说明

2026-10-06。原生微信小程序，当前契约 **0.1.57**；本轮仅修改 longju-miniapp。

## 工程

- `src/pages`：四个 Tab 与申请、名录详情、活动详情、公告、资料、报名、反馈、协议、关于、账号页面。
- `src/components`：加载/错误/空状态、活动卡片、申请/资料共用字典表单。
- `src/api/schema.d.ts`：从后端 OpenAPI 生成的类型。哈希见 `contract-version.json`，无跨仓运行时导入。
- `src/api/client.ts`：已使用端点的类型化方法；ID 始终为字符串。
- `src/api/request.ts`：微信 code 换会话、单次并发登录恢复、错误信封、If-Match、幂等头。令牌保存在微信本地存储；表单、电话、签到码与照片票据不持久化、不打印日志。
- `src/lib/intent.ts`：同一表单在超时/503 后保留 UUID；编辑形成新意图；429 遵循 Retry-After。不自动重发网络失败写请求。
- `scripts/build.mjs`：每模块独立 CommonJS 编译，保持认证模块单例；仅打包二维码依赖。TypeScript、测试、密钥配置均不进入代码包。

首页按定位/欢迎语、44px 公告、加入卡片、近期活动排序；多公告使用原生 swiper 每 5 秒切换，动效 350ms。当前使用自定义顶部导航与底部 Tab，以适配左对齐品牌标题、返回按钮、选中底块和平台安全区。采用浅砂墨金色值、已许可的莫高窟和驼队装饰，不使用设计示例活动照片或统计。自定义导航/Tab 已通过本机 wcc/wcsc 编译，模拟器与多机型位置仍待视觉验收。

## 当前实现与契约差异

| 项目         | 当前契约/实现处理                                                                                                                                                                                                                                     |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 首页 `/home` | 当前 OpenAPI 无该路径；独立读取公告、活动、本人状态，某一接口失败不抹掉其他成功内容。                                                                                                                                                                 |
| 资料与隐私   | 当前只提供 `PATCH /me/profile`，包括头像 ID 和名录/电话开关；没有旧快照的 `PUT /me/privacy`。微信官方类型不支持 PATCH，保存明确失败，不把它强转成 GET 或自创方法覆盖头。兼容补丁见 PROFILE-COMPATIBILITY.md，待跨仓授权。                             |
| 名录筛选     | 当前只接受 `query` 姓名搜索和分页；不发送未支持的家乡/区域/行业筛选，也不伪装为全量客户端筛选。                                                                                                                                                       |
| 申请         | 使用后端实时字典；提交/补充使用幂等键，已有申请使用 If-Match；以当前 qualification 判断成员资格，不能从历史 APPROVED 推断。                                                                                                                           |
| 正式协议     | 原型明确写着待运营确认。前端 agreement.body/version 留空并关闭提交，不能仅因后端配置 202601 就把原型两段文字当作正式协议。                                                                                                                            |
| 活动人数     | 占用、余位、报名/签到人数来自服务端。ActivityView 当前未返回 companionLimit，表单只按提交契约提供 0–2 同行人数，并明示实际限制由服务端校验；需后续补活动级上限以收窄选项。                                                                            |
| 媒体         | 封面/回顾/成员头像的链接需 Bearer 票据；匿名不伪造公开 COS 链接。图片预览前重新申请票据，按照片原顺序交给 wx.previewImage。当前原对象策略不生成前端假缩略图。                                                                                         |
| 签到码       | 本地生成仅含接口返回随机 token 的二维码，不含姓名/电话/报名 ID；不请求外部二维码服务。按服务端时间校准倒计时，隐藏/离开页立即清除。现有管理端直接接收 43 字符 token；历史文档提到的额外协议标识未定义解析规则，未自行创造，现场扫码协议仍待两端联调。 |
| 退出/注销    | 退出用 profile.version、If-Match 和幂等键，明确已有报名保留；注销使用新 wx.login code，成功仅宣告 CLOSING/受理，不宣称异步清理已完成。未对真实账号执行过此类写操作。                                                                                  |

## 配置与操作

1. Node 22+，`npm ci` 后执行 `npm run dev`，保留监听进程。新增 TypeScript 文件后重启监听，已有文件修改自动编译。
2. 微信开发者工具导入仓库根目录。构建产物已位于 `dist/`；工具不需要再执行「构建 npm」。
3. 手机本地预览时，电脑和手机连同一 Wi-Fi，在终端用电脑局域网地址启动构建监听，例如 `LONGJU_API_ORIGIN=http://192.168.1.140:8081 npm run dev`。把开发者工具导入项目后点「预览」生成二维码，手机打开后从右上角菜单开启调试。局域网地址会随网络变化；仅开发版允许 HTTP 本机地址，体验版/正式版会拒绝，不能用「上传」后的体验版连本机服务。此方式仅用于受信任局域网调试。
4. 真实微信登录使用与后端配置一致的 AppID。AppID 是公开标识，可设置于 `project.config.json`；AppSecret/COS 密钥绝不进入本仓。真机需可达的 HTTPS 服务与微信后台合法域名配置，127.0.0.1 仅表示运行端本机。
5. 正式发布前将 `src/config/runtime.ts` 改为正式 HTTPS 源和运营确认的完整协议、版本，并与后端当前 agreement-version 一致。还须完成资料方法兼容、微信隐私配置和文档中的剩余验收。
6. 只在明确同步契约时执行：`npm run contract:sync -- /绝对路径/longju-api/contracts/openapi.yaml`；之后 `npm run format`。普通安装、构建与测试不读取其他仓库。

原生编译脚本默认定位 macOS 微信开发者工具。其他安装位置用 `WECHAT_COMPILER_DIR` 指定含 wcc/wcsc 的目录。未找到工具时检查失败，不冒充通过。

## 当前验证及限度

- Node v22.22.1、npm 10.9.4、TypeScript 5.9.3。官方类型包 5.2.3，项目最低配置基础库 3.7.12。
- 类型检查、构建、27 项行为测试通过；18 个 WXML 文件和 1 个 WXSS 文件通过原生编译；测试为 wx/API 测试替身，不代表微信登录、审核写库或扫码通过。
- 本机实际匿名字典读取：14 个甘肃市州、13 个西安区县、20 个行业；有效公告返回空列表。匿名 `/me`、`/members` 返回 401。
- 本机 `/activities` 返回 503 `TEMPORARILY_UNAVAILABLE`，请求 ID `28f78ce0-1b14-48f3-ada8-8db56feb0da2`。`npm run smoke:api` 会为此失败退出，而非把失败记录成零条活动。本轮不重启或修改后端。
- 尝试 CLI 自动化时开发者工具提示 Service Port 关闭；未启用全局服务端口，已终止本轮等待进程。未完成模拟器截图、320/390/430px 逐屏视觉检查或真机测试。
- 当前包小于 2 MiB，自动测试检查上限。生产依赖仅 qrcode-generator；其 MIT 许可随包保留，摄影出处及 CC 许可在关于页与 assets/SOURCES.md 中保留。
