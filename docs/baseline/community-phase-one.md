# 老乡社群 · 一期需求补充

更新：2026-09-21。本文件与 `ui-design-brief.md` 为当前需求基线；此前各轮记录、截图及 PDF 保留为历史证据。

## 称谓与定位

品牌保持「西引力.陇聚」，产品定位为服务在西安的甘肃老乡的社群。对外使用「老乡社群」，不使用「老乡会」「同乡会」或「秘书处」。

| 场景 | 当前文案 |
| --- | --- |
| 首页定位 | 西安 · 甘肃老乡社群 |
| 加入卡片 | 加入老乡社群 |
| 申请操作 | 申请加入 |
| 申请表与协议 | 申请资料、加入须知与隐私说明 |
| 公告与发布者 | 社群公告、社群运营组 |
| 活动组织者 | 社群活动组 |

称谓覆盖游客、待审核、审核结果、老乡录无权限、我的、帮助、隐私、公告与活动回顾。审核流程及资料访问权限不因更名改变。

## 首页信息顺序

品牌与定位 → 欢迎语「相聚长安，共叙陇情」→ 单行公告 → 加入社群卡片 → 近期相聚 → 底部导航。

公告沿用 44 px 高、轻底色、小图标的样式；不增加大型宣传横幅。卡片仍保留莫高窟点缀。欢迎语位于卡片外，公告与卡片间距须避免装饰遮挡公告。

- 无有效公告：隐藏整栏并收起间距。
- 仅一条：静态展示；多条：每 5 秒切换，动效 350 ms。
- 点击整栏进入对应详情，长标题单行省略，详情展示全文。
- 从详情返回原首页，保留游客或待审核状态；公告不改变申请进度。
- 管理员维护标题、正文、排序、发布状态与展示时间；这些是开发要求，目前设计使用示例数据。

## 一期导航与二期产品规划

本轮建议沿用原一期范围：首页、老乡录、活动、我的。暂不新增产品、商城、好物或福利入口，不展示「暂未开放／敬请期待」占位，也不通过首页广告或我的页面提前导入商品。

原因：一期的主要价值是认识老乡与参与活动；不可用入口增加无效操作，也容易让用户先形成商业化印象。二期产品能力保留在需求规划和架构扩展中即可。

后续确有可用商品或服务，并具备履约、售后与内容管理能力后，再评审入口：以便民信息为主时可考虑「服务」；以商品交易为主时应使用能准确反映内容的名称，不以「福利」隐藏商业性质。是否增加第五个底部入口由届时的使用频率和业务范围决定。
